# Generated art direction — v0.4

Built-in image generation, transparent PNG. Original hand-painted fairy-garden mobile game sprite atlas. Four columns, three rows, isolated complete objects on genuine transparency; soft warm lighting, rich organic textures, no text or grid lines. Front-facing orthographic objects with slightly visible top surfaces; no isometric ground.

Row 1: matching white fluffy rabbit idle, happy hopping and blinking, pink inner ears, expressive brown eyes, green scarf; leafy orange carrot.
Row 2: flowering leafy shrub; compact broadleaf tree; rounded mossy rock; pink/white flowers with red mushroom.
Row 3: closed vine-covered wooden gate; matching open gate; orange checkpoint flag in a stone/leaf ring; silver spikes in a soil patch.

The original PNG is retained unchanged. Source rectangles are defined in js/art.js to accommodate the generated spacing. Assets are integrated into the actual game renderer and embedded in the standalone edition.
